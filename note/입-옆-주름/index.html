입 옆 주름의 원인은 무엇인가요

며칠 전 거울을 보다가 입 옆 주름이 깊어진 게 느껴져서 많이 놀랐거든요. 처음엔 잠깐 그러다 말겠지 싶었는데 시간이 갈수록 더 심해지는 것 같아서 스트레스가 이만저만이 아니에요. 특히 웃거나 말할 때 주름이 더 도드라져 보여서 사람들과 얘기하는 것조차 부담스러워졌어요.

주름이 심해지는 증상은 어떤 것이 있나요

그러던 중에 친구들을 만났는데 다들 얼굴이 피곤해 보인다고 해서 더 속상해졌어요. 아마 입 옆 주름 탓에 전체적으로 나이 들어 보여서 그런 얘기가 나온 것 같더라고요. 인터넷으로 관련 정보를 찾아보니까 나이 들면서 자연스레 생기는 현상이라고는 하는데 그래도 받아들이기가 쉽지 않네요.

관리 방법으로는 어떤 것들이 있나요

어떤 분은 이것 때문에 우울증까지 왔다는 글도 봤는데 저도 그렇게 될까봐 겁이 나요. 그래서인지 요즘엔 가리려고 화장을 진하게 하는데 오히려 더 어색해 보이는 것 같더라고요. 마스크를 쓰고 있을 땐 괜찮은데 벗어야 할 때는 자꾸 신경 쓰여서 집중이 잘 안 돼요. 사진 찍을 때도 보일까봐 각도를 이리저리 신경 쓰다 보니 자연스러운 표정 짓기가 힘들어졌어요.

마스크를 쓰면 상태가 더 나빠질까요

개선하는 방법도 이것저것 알아봤는데 비용이 부담스러워서 쉽게 결정을 못 내리겠어요. 그렇다고 이대로 계속 깊어지는 걸 지켜보고만 있기도 힘들어서 정말 고민이 많아요. 요즘은 이것 때문에 외출도 꺼려지고 사람 만나는 것도 부담스러워서 자꾸 집에만 있게 되네요. 혹시 비슷하게 입 옆 주름 때문에 힘드셨던 분들 어떻게 극복하셨는지 조언 좀 부탁드려요ㅠ
